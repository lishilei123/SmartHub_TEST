# MiniTask 需求说明

## 项目目标
MiniTask 是 SmartHub AI 自动化测试平台的测试靶场，用于验证需求分析、测试设计、API/UI 自动执行、缺陷识别和测试报告能力。

## 功能范围

### 登录
- 支持用户登录。
- 正确账号密码登录成功。
- 错误密码必须返回失败。

演示账号：admin / admin123

### 项目管理
- 新增项目
- 查询项目
- 修改项目
- 删除项目
- 项目名称不能为空
- 删除项目需要确认
- 删除项目需要同步删除任务

### 任务管理
- 新增任务
- 修改任务
- 删除任务
- 查询任务
- 标题不能为空
- 优先级：high、medium、low
- 状态：todo、in_progress、completed

### 状态规则
任务状态只能：

todo -> in_progress -> completed

已完成任务不能回退。

### 查询
支持：
- 状态筛选
- 优先级筛选
- 关键字搜索

### Dashboard
展示：
- 项目数量
- 任务数量
- 已完成数量
- 未完成数量
